# Brand Guidelines: Perspective AI

This document details the visual identity guidelines for **Perspective AI** as well as the parent **AOSSIE** organization.

---

## 🎨 Perspective Color Palette

Perspective AI employs a dual-theme visual design system supporting high-contrast Deep Navy Blue and Warm Biscuit Cream:

| Theme | Color Name | Sample | HEX Code | Role |
| :--- | :--- | :--- | :--- | :--- |
| **Dark Theme** | Deep Midnight Navy | 🟦 | `#02183c` | Primary Dark Background |
| **Dark Theme** | Secondary Navy | 🟦 | `#052352` | Dark Card & Surface |
| **Dark Theme** | Ice Accent Blue | 🧊 | `#dbeafe` | Primary Dark CTA Button |
| **Light Theme** | Warm Biscuit Cream | 🟨 | `#f6eedb` | Primary Light Background |
| **Light Theme** | Warm Surface | 🟨 | `#faeecf` | Light Card & Surface |
| **Light Theme** | Charcoal Primary | ⬛ | `#18181b` | Primary Light CTA Button |

## ✍️ Typography

- **Default Font Family:** **Inter**
- **Fallback Stack:** `ui-sans-serif, system-ui, sans-serif`
- **Configuration:** Set globally via Tailwind CSS custom theme bindings inside [`globals.css`](../../app/globals.css).
